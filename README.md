## 🚀 How to Deploy in Under 60 Seconds

You mentioned you already have active **GitHub** and **Vercel** accounts. Here are the two simplest ways to make your portfolio live:

### Method 1: Deploy with Vercel (Recommended)
1. Push this directory to a new repository in your GitHub account:
   ```bash
   git add .
   git commit -m "feat: complete executive portfolio & career assets"
   git branch -M main
   git remote add origin https://github.com/<your-username>/utkarsh-seth-portfolio.git
   git push -u origin main
   ```
2. Log into [vercel.com](https://vercel.com).
3. Click **"Add New Project"** and select your `utkarsh-seth-portfolio` repository.
4. Leave all build settings as default (Framework Preset: **Other**) and click **"Deploy"**.
5. Your portfolio is immediately live worldwide at `https://utkarsh-seth-portfolio.vercel.app` (with automatic free SSL and CDN caching).
6. *(Optional)* In Vercel Project Settings > Domains, add your custom domain (e.g., `utkarshseth.com` or `utkarshseth.in`).

---

### Method 2: Deploy with GitHub Pages (100% Free)
1. In your GitHub repository, go to **Settings** > **Pages**.
2. Under **Build and deployment > Branch**, select `main` and `/ (root)`.
3. Click **Save**.
4. In 60 seconds, your site is live at `https://<your-username>.github.io/utkarsh-seth-portfolio/`.

## 🖨️ How to Generate Your Executive PDF Resume

1. Open `resume/index.html` in Chrome, Brave, or Safari.
2. Press **`Cmd + P`** (Mac) or click the **"Print / Save as PDF"** button at the top banner.
3. In the print dialog:
   * **Destination:** Save as PDF
   * **Paper Size:** A4 or Letter
   * **Margins:** Default (or None)
   * **Background graphics:** Checked (ON)
4. Click **Save**. You now have an immaculate, ATS-friendly executive CV ready to send to recruiters and C-suites.
